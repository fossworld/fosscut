# App icon

`icon.png` (512x512) and `icon.ico` (16 to 256 pixels) were drawn for FossCut by `make_icon.py` in this folder: a play triangle split by a diagonal cut on a dark rounded square. They are part of FossCut and licensed like its code, MIT OR Apache-2.0.

Regenerate them with Pillow installed:

```bash
python3 apps/desktop/icons/make_icon.py apps/desktop/icons
```
